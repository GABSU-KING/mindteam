# 마인드팀 (MindTeam)

마음속 감정들이 서로 대화하고, 사용자는 그 대화를 지켜보다 끼어듭니다.
개입이 쌓일수록 각 감정 에이전트의 성격이 아주 조금씩 변합니다.

영화 *인사이드 아웃*에서 착안했습니다.

## 이 저장소

웹 앱 설치와 실행은 [`web/README.md`](web/README.md)를 보세요.

## 핵심 개념

**가중치 기반 발화.** 대화는 라운드로빈이 아닙니다. 각 감정의 `weight`를 확률로 삼아
매 라운드 2~4명을 뽑고, 뽑힌 감정만 자기 `system_prompt`와 성격 벡터로 발화합니다.

**감정은 고정되어 있지 않습니다.** 가입 시 다섯을 시드하지만 사용자가 추가·삭제할 수 있고,
활성 2~8명 사이에서 자유롭게 구성합니다. 코드 어디에도 감정 종류가 하드코딩되어 있지 않습니다.

**성격은 천천히 변합니다.** 한 번의 개입으로 성격 벡터가 움직일 수 있는 최대치는 0.05입니다.

## 주의

마인드팀은 **스크리닝 보조 도구이며 진단 도구가 아닙니다.** 여기서 생성되는 어떤 문장도
의학적 판단이 아닙니다. 힘든 상태가 이어진다면 전문가와 이야기해 보시길 권합니다.
